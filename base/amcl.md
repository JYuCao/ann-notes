# AMCL 的全局重定位

AMCL（Adaptive Monte Carlo Localization，自适应蒙特卡洛定位）基于粒子滤波，用来估计机器人在已知地图中的位置和姿态。

全局重定位是 AMCL 的关键特性，允许机器人在完全未知的初始位置的情况下，通过传感器数据逐步确定其在地图中的位姿。

AMCL 通过以下步骤实现全局重定位：

1. **粒子初始化**： 在全局范围内随机均匀生成粒子，覆盖整个地图。
2. **传感器更新**： 使用传感器数据（通常是激光雷达）为每个粒子计算权重。
3. **粒子收敛**： 随着多次传感器更新，粒子群逐渐集中到符合机器人实际位置的区域。
4. **重采样**： 不断更新粒子分布，剔除权重低的粒子，从而提高估计的准确性。

特征：

* **鲁棒性**： 即使机器人位姿完全未知，也能逐步定位。
* **计算复杂度较高**： 由于粒子分布覆盖全局，计算量显著增加。
* **收敛速度依赖地图特征**： 地图特征越多，重定位越快；若地图较为空旷，可能需要更多时间。
