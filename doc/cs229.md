## Supervised Learning
- Linear Regression
    - LMS: $J(\theta) = \frac{1}{2} \sum_{i=1}^{n} (h_\theta(x^{(i)}) - y^{(i)})^2$
- Logistic Regression
    - Sigmoid/Logistic Function: $h_\theta(x) = \frac{1}{1 + e^{-\theta^T x}}$
    - Mutil-class Classification
        - Softmax Function: $h_\theta(x) = \frac{e^{\theta^T x}}{\sum_{j=1}^{k} e^{\theta_j^T x}}$
        - cross-entropy loss: $l_{ce}((t_1,\dots,t_k),y) = -\log(\frac{e^{t_y}}{\sum_{j=1}^{k} e^{t_j}})$
    - Newton's Method / Fisher Scoring: $\theta := \theta - H^{-1} \nabla_\theta J(\theta)$
- GLM（Generalized Linear Models）
    - Exponential Family: $p(y;\eta) = b(y) \exp(\eta^T T(y) - a(\eta))$
    - Link Function
- GLA（Generalized Linear Algorithms）
    - Gaussian Discriminant Analysis / GDA Model
    - Naive Bayes
    - Laplace Smoothing
    - Multinomial Event Model
- Kernel Methods
    - Kernel Trick: kernel matrix should be PSD (Positive Semi-Definite)
- Support Vector Machines
    - Functional / Geometric Margin
